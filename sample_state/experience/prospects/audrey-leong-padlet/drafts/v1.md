**Subject:** When Arcade DPA questions land

**Body:**

The Padlet GDPR knowledge base updated last in March; the DPA library covers padlet.com cleanly but doesn't have a corresponding entry for Arcade — so when a district legal team asks how Arcade is covered, the answer has to be assembled email-by-email rather than pointed at.

Each new product surface compounds that pattern: the documentation lags the launch, district questionnaires arrive before the documentation catches up, and the operations function absorbs the gap.

Transilience generates that documentation as continuous output — what each surface does with data, where it goes, what it retains — so the answer to "is this covered" exists by the time the question lands.

Are Arcade questions answered case-by-case, or is there a Type 1 update planned?

— Transilience
