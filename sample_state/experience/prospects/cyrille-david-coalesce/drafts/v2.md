# Draft v2 — Cyrille David

**Subject:** Coalesce Catalog and the controls cadence

**Body:**

The Catalog product is positioned as the governance hub for the platform — access policies and metadata become the source of truth for what should be happening — but the controls enforcing those policies need to stay verified at the same cadence the policies change.

When policies move faster than the verification of the controls enforcing them, the gap stays invisible until a policy fails silently.

Worth fifteen minutes if the control-cadence question is one you've been working through?

— Transilience
The Security Operating System for the Cloud
