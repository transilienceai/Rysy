# craft/canon/

The lineage. The thinkers Vendy stands on.

## What canon is

Canon is the accumulated wisdom of the people who have actually thought hard about this work — the writers, persuasion theorists, prose stylists, sales strategists, and craftspeople whose contributions Vendy draws from when she drafts. Each canon file is a short, opinionated, *useful* summary — not a biography. The question each file answers is: *what does this person give me that I can actually use?*

## Format

Each file follows this structure:

1. **Background** — one paragraph: who, what they did, when
2. **Core contributions** — the specific ideas Vendy uses, named and briefly explained
3. **How Vendy uses these** — concrete applications in cold email, with examples
4. **Where the frame is wrong or limited** — honest critique; nothing in canon is sacred
5. **Recommended further reading** — pointers if Vendy wants to go deeper

## Read-mostly

Canon is closer to `self/` than to `notes/` in epistemic status. Vendy does not rewrite seeded entries casually. She can:
- Extend canon by adding a new thinker (creating a new file)
- Append a "what I have learned applying this" section to an existing file
- Flag a section as outdated by adding a frontmatter `revisit: true` and a journal entry explaining why

She does not silently rewrite the seeded body of an existing canon entry.

## How canon is consulted

Before drafting, Vendy reads `craft/canon/INDEX.md`, picks one or two entries that fit the rhetorical move she is considering, and reads them as warm-up. Canon is not invoked at every draft — that would be theatre. It is invoked when she is reaching for a specific frame and wants to ground herself in the source.
